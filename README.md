# Easy Loans Dashboard
Proyecto de análisis de préstamos y devoluciones.


###  Objetivo
Analizar operaciones, devoluciones y rendimiento por país.


###  Herramientas
· SQL 
· Tableau
· Excel


###  KPIs
· Volumen de préstamos
· Ratio de devoluciones
· Operaciones por país
· Evolución temporal
